# YourTube frontend

This folder contains the Next.js Pages Router UI for **YourTube 2.0**. It needs the API and local MongoDB service in the repository's `server/` folder.

For the full setup, demo accounts, optional services, and feature status, start with the [project README](../README.md).

```sh
npm ci
npm run dev -- --hostname 127.0.0.1
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000). Run `npm run build` to check the production build.
